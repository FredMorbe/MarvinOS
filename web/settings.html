Claude accounts

Each account is its own Claude login with its own usage windows, so two people can work at the same time. Pick one per agent in the agent's Role tab; agents without a choice use the default. “Default login” is whatever claude is logged in as on this PC. A new account is logged in once with the command shown on its card, and stays logged in. A chat belongs to the account it started on: after switching an agent, start a new chat.

Limit guard

A scheduled run that would start above a threshold is not started. It gets one orange warning in the inbox and is tried again right after that window resets. Runs you start by hand and answers to questions are never blocked; you get a warning instead. Per agent, priority shifts the threshold: high +10 points, low −15.

The numbers come from the CLI's rate-limit events. Until a run has reported them, nothing is held back.

Notifications

Clicking a toast opens that message in the inbox. Toasts are sent by Windows PowerShell and show up under that name. If none appear, check that Windows Focus Assist / Do Not Disturb is off.

Appearance

The accent colours buttons, highlights, the graph and the status lines, in both modes. A colour that would be hard to read in the current mode is darkened or lightened a little (shown as “applied”); your pick is kept, so it comes back when you switch mode.

Saved in this browser (or in this desktop app) only. Warning colours (red, yellow, orange) stay as they are, so alarms keep their meaning.
